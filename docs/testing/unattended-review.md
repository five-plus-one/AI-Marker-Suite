# 无人模式待复核

“AI 作答状态核对”为默认关闭的实验选项，按方案保存。关闭时，三种模式都沿用有效分数的处理流程；作答状态不会触发这项实验的重试、暂停或待复核累计，已有待复核记录也不会触发数量阈值。旧方案迁移及未明确启用的导入方案保持关闭。

主动开启后，无人模式遇到明确“无法辨认”的作答时，使用同一份图片和评分方案重新请求一次。重试后仍无法辨认时，保留模型返回的有效分数，按现有评分规则填分和提交，并在评阅历史中留下待复核记录。普通模式和试改模式交教师核对，新增的作答状态一致性检查也在开启后生效。

待复核记录保存本卷原图、题目标识、评分方案、识别结论和给分。记录与图片保存完成后才填分；提交接口返回成功后才写入提交分数。平台提交失败时保留“待提交”状态，不增加批阅进度。平台是否真正保存、是否已进入下一份，仍由各适配器的提交和换卷校验负责。

设置位于“自动化 → 自动重试 → AI 作答状态核对”。开启后可设置“无人模式允许待复核数量”，默认允许 5 份；前 5 份继续，第 6 份提交后暂停。设为 0 时，首份待复核卷提交后暂停。累计范围为当前脚本保存的全部待复核记录，刷新后继续保留；同一平台、同一任务、同一份答卷只计算一次。没有原生卷号时比较已存原图。

教师在“评阅历史”中筛选“待复核”，查看原图及当时的评分方案，在平台核对或修正分数后点击“完成复核”。可以重新标为待复核。记录未完成复核时保留原图与材料；导出 JSON 和材料包可保留完整评分方案。

无法取得图片、缺少有效分数、分数不完整、原有的明确整卷未作答正分冲突，以及填分和平台提交失败，继续沿各自的错误路径处理。识别重试与接口瞬态错误重试独立。

验证入口为 `tests/unattended-recognition-retry.test.js`、`tests/unattended-review.test.js`、`tests/blank-answer-evidence.test.js` 和 `tests/image-gate.test.js`。本地确定性测试核对流程与请求载荷，不代替不同视觉模型对真实卷面的识别测试。
