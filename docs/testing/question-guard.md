# 题号变化暂停

设置位于「批改 → 答卷校验」，实验选项默认关闭。开启后，脚本在本次启动时记录题号与小题满分；同题换卷维持该基准。检测到题号、评分项或小题满分变化时暂停，教师核对当前题目与评分方案后点击继续。

目前覆盖智学网和好分数的已识别评分栏。智学网优先读取评分框前的大题题号与各小题标识；好分数读取各评分框前的题号。读取不到完整题号时不能完成开启状态下的校验，应等待页面加载或联系作者适配。

## 校验位置

- 取图前、AI 返回后的填分前、确认窗口提交前。
- 运行期间轮询，变化时取消当前请求、确认倒计时与页面自动恢复标记。
- 新一份答卷沿用本次启动的题目基准，教师主动继续后才建立新基准。
- 关闭时不读取题号，沿用原有答卷一致性与任务校验。

## 回归依据

`tests/question-guard.test.js` 驱动主流程与确认回调，覆盖同址换题、同题换卷、AI 期间换题、三种模式的提交拦截、页面过渡、配置迁移及继续操作。`tests/fixtures/question-guard.html` 使用与实际评分栏一致的匿名 DOM 结构验证适配器，并检查设置入口与窗口边界。

实际阅卷保存仍由平台适配器处理。题号检测用于检查当前题目与本次批改任务是否一致，不验证教师填写的评分标准内容。
