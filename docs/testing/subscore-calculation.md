# 小题给分算式与汇总核验

对应 Issue #412，稳定版 1.21.22.0。

## 数据路径与根因

`callAIGrading → parseSubQuestionResponse → parseSubQuestionScores → ScoreCalculator.calculate → adapter.fillScores → showAutoSubmitDialog`。双评在 `callDualEvaluation` 比较两侧总分并合并各单元，仲裁同样调用小题解析器。

此前结构化和旧格式解析均只读取小题字段中的首个数字。`1+0+2=3`、`0+0+0+1=1`、`0` 被读成 `[1,0,0]`，计算器按明细汇总为 1。相同返回样例在 v1.21.19.0、v1.21.20.0 和 v1.21.21.0 中均能复现。

当前解析完整的数字、加减算式及等式；等式两侧需一致，缺失或不确定的得分保留 null。结构化及旧格式共用字段提取，完整明细统一汇总为 score 与 rawScore，使双评阈值使用的总分与明细一致。原始评分段落继续保留供核查。
