# 阅卷现场留档与回归

每次取得获授权的测试账号，都先建立本地现场档案，再开始适配或排查。账号到期后，档案继续用于真实页面结构、资源格式和操作时序的回归。每个平台、部署、任务类型分别登记，新增现场保留为新批次。

## 保存范围

本地档案放在工作区外层的 `LocalPlatformScenes/<platform>/<date>/<scene>/`，通过本地 Git 排除规则隔离，并限制为当前用户、管理员及 SYSTEM 访问。档案保留供本项目维护使用；公开测试另建经过审查的脱敏样本。

一次完整的采集记录应包括：

- 平台入口、部署版本、任务模式、脚本版本、采集时间和操作者实际执行的操作。
- 页面与各可访问 iframe 的 HTML、DOM 状态、布局、截图；Canvas 位图和 SVG 资源也单独保存。
- 当前任务加载的前端脚本、样式、字体、图片及依赖清单；保留原始字节、相对引用、MIME 和 SHA-256，登记失败、未缓存或未加载的资源。
- 与当前任务相关的接口请求方法、脱敏路径、业务参数、响应、先后关系、对应任务及答卷标识。采集前开始监听，缓冲区截断必须登记；提交接口与读接口分别标记。
- 任务进入、图片就绪、输入模式、满分与梯度、自动提交开关、填分、确认、保存成功、换卷、失败与重试等状态及跳转条件。只登记实际观测到的状态；未执行的步骤保留为覆盖缺口。
- 评分标准与参考资料，以及每个状态对应的答卷资源、接口样本和时间。不同答卷、不同时间的截图不能拼接成同一状态。
- `capture.json` 覆盖说明、`resources.json` 资源索引、`files.json` 全文件完整性清单、回放结果和阅读说明。

浏览器可获得的是已下发的前端程序和观测到的接口行为。服务端实现、未进入的任务、没有执行的保存/仲裁等流程，必须在覆盖说明中明确登记。首次只有部分样本时也应立即存档，后续按任务增补。

账号密码、Cookie、Authorization、会话存储、验证码和支付信息不进入场景档案。资源签名和接口中的身份、联系方式等按用途脱敏；HTML、DOMSnapshot 字符串及输入值同样检查，平台以外的配置面板从采集范围移除。私有答卷仍只保留于本地受限目录。需要登录才能重新取资源时，使用原平台正常登录流程。

## 回放与核验

在 Core 仓库运行：

```powershell
node scripts/platform-scene.cjs verify <本地场景目录>
node scripts/platform-scene.cjs serve <本地场景目录> 10452
```

`verify` 校验资源和已有的全文件清单。`serve` 在 `127.0.0.1` 提供只读页面，拒绝写请求并限制外部连接。关闭服务使用 Ctrl+C。

当前实现提供冻结 DOM 的适配器回放：保留真实 DOM、布局和图片，隔离平台运行脚本和提交动作。好分数可调用 `window.sceneProbe.run()` 比较当前适配器与 `v1.21.19.0`、`v1.21.20.0`、`v1.21.21.0`、`origin/stable` 的取图结果；历史探针由 `/adapter-probe.js?ref=<版本>` 加载。采集时将用于对照的历史 `selectors.js`、`adapter.js` 保存进档案，并在 `capture.json.adapterVersions` 登记每个版本的路径，由全文件清单校验；回放优先使用已归档代码，未归档版本再从本地 Git 读取。原始平台脚本作为证据保存，冻结回放的成绩输入与原生保存流程并不执行。

扩展完整交互回放时，应按档案中的接口契约、顺序及状态建立本地模拟服务，验证正常、延迟、同卷重取、失败、任务结束和恢复流程。保存与换卷验收需要对应现场或明确获授权的测试任务；冻结快照通过不能替代这项验收。

## 发布前兼容矩阵

修改取图、身份判定、填分、提交或换卷时，先审阅整个函数及其调用链，再对照上个稳定版、新版和最初现场。公共逻辑修改必须列出所有受影响适配器。

| 检查面 | 必须说明的证据 |
| --- | --- |
| 页面与资源兼容 | 原有与新增部署、相对/绝对地址、SVG/Canvas/图片、已观察到的路径和编码形式 |
| 同卷等待 | 输入框为空/被清空、零分、同卷重取、签名刷新、接口迟到、加载过渡 |
| 完整答卷 | 多图齐备、旧图隐藏、混合新旧卷、图片加载失败、未知格式 |
| 连续阅卷 | 提交前建立基线，确认保存后进入下一份；任务切换、暂停、退出及恢复 |
| 工作模式 | 试改、普通、无人三种模式分别记录；试改通过只证明它实际经过的路径 |
| 验证等级 | 真实账号观测、离线场景回放、受控单元用例、未覆盖行为分别列明 |

旧格式能否继续取图，必须有对照用例。新增识别规则只有在已有取图支持上完成兼容核验后，才可用于过滤原有图片。缺少账号或样本时记录明确缺口，不将单元测试数量当成全部平台的现场验收结果。
