# 温州云阅卷适配调研与验收

温州云阅卷入口为 <https://yuejuan.wzedu.cn>，由吉林华翰云提供，阅卷模块采用 Vue 3.2.47 和 Element Plus。适配复用 `huahanyun` 模块，并为温州部署增加页面识别、评分状态绑定和任务区分。

调研日期为 2026 年 11 月 12 日。验收对象为七年级社会第 31(1) 题，平台满分为 3 分。平台登录、任务列表、阅卷页、答卷图和评分绑定均经过实际访问验证。

## 页面与交互

| 页面 | 地址或特征 | 脚本行为 |
| --- | --- | --- |
| 登录 | `/index` | 使用平台原有登录方式 |
| 任务列表 | `/static-v2/exam/index.html#/marking/gradingList/list` | 等待进入阅卷页 |
| 阅卷 | `#/marking/grading?questionId=…&thisType=…&isSchool=…&choiceIndex=…` | 分数框和给分按钮就绪后激活 |
| 一键给分 | `.redbiginput input.el-input__inner[placeholder="请给分"]` | 更新当前题目分数，保留平台给分按钮作为提交入口 |
| 键盘给分 | `input#compuinput`，兼容容器内的实际输入框 | 更新当前题目分数，提交交给核心批改流程 |
| 给分 | `button.submitscorebtn` | 点击可见、可用的按钮，等待本卷保存回执 |
| 回评或只读 | `review=true`、`markReview=true`、`readonly=true`，以及平台当前阅卷状态 | 保留平台人工操作 |

默认的一键给分框为只读输入框，另外存在步长设置输入框。适配按评分框的专用结构定位，步长设置不计入评分单元。平台采用单题块评分，一个阅卷任务对应一个分数。

## 填分与提交

温州页面通过 `#app.__vue_app__.config.globalProperties.$store` 暴露 Vuex。题号和满分取自 `state.mark.readOverInfo.question`，题目状态中的 `markingType` 为 1 或 2 时，分别支持键盘给分和一键给分。合批、分项、批量及批注给分由平台原生流程处理。

填分调用平台已有的 `mark/SET_SCOREING` mutation，并同步更新输入框的展示值。填分后同时校验平台分数与展示值。这个 mutation 只更新评分状态；平台键盘输入事件会根据 `inputFastSumbitFlag` 执行快捷提交，因此适配通过评分状态绑定保持填分与提交两个独立步骤。平台评分绑定不可用时，填分返回失败，核心流程暂停。

实际页面中将 2 分填入满分 3 分的题目后，平台的 `questionScore` 为 2，输入框显示为 2，填分阶段的网络请求数为 0。随后点击给分按钮，浏览器在发送前拦截到 `POST /v2/union/mark/submit`，其 `score` 为 2。请求包含平台自行生成的题块、考生、答卷、评分阶段和分项字段；适配使用平台按钮生成提交内容。

适配在点击前记录本卷身份、题块、答卷和分数，并观察平台自己生成的提交请求。只有请求内容与本轮一致，且收到 HTTP 成功、平台 `code: 200` 与有效的保存结果，核心才增加批阅计数和成功历史。服务器拒绝、业务状态变化、网络错误、取消或 15 秒内未收到回执时返回失败；本轮提交期间设有重入保护。观察结束后恢复页面 XHR 方法并移除监听器。

真实账号的给分请求在浏览器发送前终止，生产成绩保持原状。完整连续阅卷使用原站公开 Vue 前端、合成教师与答卷数据，在隔离浏览器中运行最终压缩安装包。浏览器拦截全部页面请求，保存成功、服务器拒绝、业务拒绝和断网由本地响应重放；实际提交内容、平台状态、插件历史及计数均逐项核对。模型请求使用合成答卷图和模拟流式评分响应，用于验证图片请求、提示词构造、结果解析到提交的整条链路。

## 答卷与任务标识

实际答卷由同站图片代理提供，结构为：

```text
https://yuejuan.wzedu.cn/r/{deployment}:/union_new/{exam}/{subject}/{school}/student/{student}/{hash}/d2Vi/{questionId}.png
```

答卷通过与阅卷页相同域名的图片代理提供。脚本的站点匹配及图片请求权限包含 `yuejuan.wzedu.cn`。答卷图从可见的 `img.el-image__inner` 中读取，筛选带 `/student/` 路径的题块图片；同一考生的多张图一起读取。图片地址中的考生段作为答卷身份，签名或缓存参数变化保持同一身份。

多考生图片同时可见时，读取结果为空，答卷身份为空。等待下一份时，要求旧考生图退出、可见考生图集只属于一个新考生；仅更换签名、图片为空或出现多个新考生时继续等待。

温州题目方案使用 `huahanyun#wzedu#{questionId}#{choiceIndex}` 区分部署、题块和选做项，阅卷阶段切换继续沿用同题方案。鹿城部署保留已有任务标识，现有方案绑定继续使用。

## 复验

在代码工作目录执行：

```powershell
npm ci
npm test
npm run build
npm run verify:bundle
node scripts/verify-browser.cjs --fixture=wzedu
```

原站完整流程使用 Playwright 和本机 Chrome。环境中可解析 `playwright` 时直接执行；也可将 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块目录，`CHROME_BIN` 指向浏览器可执行文件：

```powershell
node scripts/verify-wzedu-runtime.cjs
```

首次执行仅下载平台公开静态资源并缓存在系统临时目录，可使用 `--assets=目录` 指定缓存。`--case=trial-two` 可单独复验某个场景。合成接口样本位于 `tests/fixtures/wzedu-api.json`，脚本运行时拦截全部生产接口请求。

`dist/ai_marker.user.js` 为完整本地适配包。平台能力通过该构建产物验收，发布渠道按项目原有流程管理。
