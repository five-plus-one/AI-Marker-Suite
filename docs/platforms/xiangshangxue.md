# 享尚学阅卷使用说明

享尚学是福建鹿鸣教育提供的网上阅卷系统。当前支持 [新罗阅卷入口](https://xinluolk.fjjxhl.com/lypaper/login.aspx)。

登录后打开“教师阅卷”，选择本次评阅的题号，点击“正常评阅”。答卷图片和评分栏加载完成后，即可使用 AI 批改助手。教师阅卷会在新窗口打开，助手在该窗口中工作。

支持正常单评、双评，以及一道题包含多个评分点的情况。助手读取当前题号和各评分点满分，按平台允许的分数填写；确认平台保存成功、下一份答卷加载完成后继续。平台设置的最少阅卷时间仍然适用。

## 开始批改

1. 安装预览版脚本，打开当前题目的正常评阅页面。
2. 在批改配置中填写本题的参考答案和评分标准，并核对题号、评分点和满分。
3. 使用试改模式检查答卷识别和评分。助手开始批改时会关闭平台“自动提交分数”，由助手的确认流程控制提交。
4. 核对结果后确认提交，再继续下一份答卷。

参考答案包含多个题目时，应为当前题目填写相应部分。多个评分点需要逐项核对；评分标准文字中的分值与平台满分不同，先向阅卷负责人确认。

## 页面提示与恢复

切换题目、答卷或评分点后，重新读取并批改当前答卷。回评、仲裁、复查、异常卷处理、选做题和减分模式需使用平台原有操作。

如果提示未确认保存结果，请先在平台核对阅卷进度与当前答卷，再继续操作。网络错误、会话过期或管理员暂停阅卷时，应恢复登录或等待平台开放。
