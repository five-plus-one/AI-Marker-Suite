# 阅卷平台使用说明

安装脚本后，进入平台的实际阅卷任务，核对评分单元、满分、参考答案和评分标准。先使用试改检查识别与评分结果，再确认提交。

| 平台 | 适用任务与开始前的设置 | 详细说明 |
| --- | --- | --- |
| 文通云 | 普通单题一键给分，按平台提供的分值评分 | [使用指南](https://aimarking.five-plus-one.com/platforms/wentongyun) |
| 小闲 AI | 普通单题键盘给分，关闭平台自动提交，核对合法分值和步进 | [使用指南](https://aimarking.five-plus-one.com/platforms/xiaoxianai) |
| 丽升 | 正评的打分板给分，英语填空或写作；关闭平台二次给分确认 | [使用指南](https://aimarking.five-plus-one.com/platforms/leascent) |
| 天喻慧学与惠州市智慧教育平台 | 普通阅卷，按当前题目允许的分值评分 | [使用指南](https://aimarking.five-plus-one.com/platforms/huixue) |
| 优分优学 | 普通单评的键盘给分，关闭平台自动提交 | [使用指南](https://aimarking.five-plus-one.com/platforms/youfen) |
| 小乐优阅 | 初评题块，逐项核对评分项，关闭平台自动提交 | [使用指南](https://aimarking.five-plus-one.com/platforms/xiaoleyouyue) |
| 享尚学 | 正常单评、双评与多个评分点，遵守平台最少阅卷时间 | [使用说明](xiangshangxue.md) |
| 温州云阅卷 | 单题键盘给分、一键给分及绑定批阅；绑定题按题号分别配置评分标准与满分 | [平台指南](https://aimarking.five-plus-one.com/platforms/huahanyun) |

助手确认平台保存成功、下一份答卷加载完成后继续。保存结果尚未确认时，先核对平台阅卷进度和当前答卷，再继续操作。其他阅卷模式的范围以各平台指南为准。
