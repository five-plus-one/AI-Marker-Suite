# 发布渠道审计

稳定基线：7b16991。预览基线：b2d2c5a。候选版本：1.21.26.0。

## 渠道与功能

稳定候选包含预览基线的平台适配和安全修复。精简输出、随机批改节奏和可选题号核对由渠道策略限制；稳定执行使用详细输出、固定节奏和答卷校验。方案原始配置保留，运行使用独立快照。智学网连续切题保护继续独立生效。

## 风险与回归

- 答卷身份：签名续期、裁切参数、多图过渡、旧新图片混合、同卷分数清空及下一份加载。
- 给分：完整小题算式、明细合计、重复或缺失字段、满分与步长、单评/双评/仲裁一致性。
- 保存：平台自动提交关闭、成功回执关联、网络失败、末卷结束、迟到模型响应与暂停取消。
- 配置：导入、跨渠道切换、刷新、运行快照和存储数据隔离。
- 页面：宿主按钮样式隔离、共享工具栏及提示、宽窄窗口与深浅主题。

空白卡快捷路径现将当前识别答案设为“空白答题卡”，再打开确认窗口，避免继承上一份答案。
