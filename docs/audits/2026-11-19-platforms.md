# 近期阅卷平台与诊断包发布审计

关联 #552。适配范围为百师联盟普通单题评阅、韬普教育云普通单题键盘给分、悦卷通键盘按题阅卷和湖北丽升正评打分板。保存和换卷回放均使用构造答卷。

| 平台 | 审计依据 | 回放覆盖 |
|---|---|---|
| 百师联盟 | 实际任务已核对单题入口、满分、步长和原始题块。原生提交通过 JSON 发送当前任务的分数。 | 原生自动提交切换、整分和半分、零分、教师改分、失败回执、本卷确认及同题换卷 |
| 韬普教育云 | [原始现场审计](2026-11-18-taowei.md)记录 2+1 作文评阅、双页题块和键盘给分。 | iframe 实际地址、给分点与图像、倒计时、确认、请求字段、失败回执及下一份答卷 |
| 悦卷通 | 平台前端标记学生与卷号，并在保存响应 result 的首字符为 0 时进入下一份。 | 题块与两小题、缺项和越界、不同卷号、业务拒绝、全零分确认、成功回执及同题换卷 |
| 湖北丽升 | 与原有丽升打分板共用原生答卷状态和保存格式，按实际阅卷域名、端口及路径注册。 | 登录路径隔离、17 分整数档、当前题块、确认保存及连续换卷 |

诊断包回放覆盖默认两小时、自选时间、非法时间、更早记录与 ZIP 内容。日志在构建时提取运行语句的固定文字，运行时保留时间、级别、来源等诊断信息。配置和评阅记录按字段取值，密钥、答卷文本及图片留在本机。输出使用构造数据核对。
