# 作答原图待复核

关联 Issue #166，开发渠道版本 1.21.25.8。

作答证据检查始终执行。保存待复核记录是默认关闭的方案选项；旧方案与导入值按布尔值迁移。开启后，普通及试改模式在明确无法辨认时保存本卷原图与评分方案并暂停；无人模式在同一答卷上下文内重试一次。识别恢复时继续既有评分流程，仍无法辨认时保存并暂停，由教师在原站核对评分。

待复核记录的最终分数保持空值，模型数字标为待核对参考分。教师可在历史记录中筛选、查看原图、导出方案和完成复核。原生答卷标识与原图共同去重，已完成记录保留。图片及历史均需成功读回，暂停或答卷变化后停止登记。

积压默认上限为5份，可设为1至50份。请求和持久化前核对数量；图片每份上限8MiB、总缓存上限50MiB，历史容量上限50MiB。容量或读写失败时停止本卷并提示处理。未完成记录保留至教师复核，批量清理、历史缩减与图片清理保护其内容。快照只包含题目、答案、评分标准与分数结构。

回归覆盖开关默认值、三种模式、重试恢复、积压上限、读写失败、图片容量、取消、换卷、去重及复核状态。浏览器场景覆盖宽窄窗口、深浅色、键盘聚焦、触屏操作尺寸和历史详情。网络、模型输出及答卷均为隔离合成材料。
