# 取图兼容与连续阅卷审计

日期：2026-11-12。关联：#406、#410。审查对象为 `src/adapters` 的 43 个适配器实现，包含尚未进入构建的 `dongni`、`xkw`。审查取图、答卷身份、换卷及相关委托函数，并对照 v1.21.19.0、v1.21.20.0、stable 1.21.21.0 与本次修复。

## 结论与证据

### 好分数版本回归

1.21.20.0 将 `/cutimage/` 的解析规则用于取图准入，漏掉此前可以获取的 `/v1/baidu-raw/` 裁切图。1.21.21.0 已兼容两种格式，并统一取图、身份和换卷使用的答卷标识。

本次保留了获授权账号中的真实界面及前端资源。冻结 DOM 的浏览器回放中，同一答题卡在 1.21.19.0 取得 1 张、1.21.20.0 取得 0 张、修复版取得 1 张。此前现场已分别验证试改、普通和无人模式的识别/评分路径，在实际填分前停止；成绩保存与连续换卷未作为已验证项目。

### 受控复现与本次修复

| 问题 | 触发条件与影响 | 当前处理 |
| --- | --- | --- |
| 九五优评漏图 | iframe 图片属性是相对/协议相对地址；代码先读原属性再按 HTTP 前缀筛选，使有效图消失 | 使用浏览器解析后的 `img.src`，明确空属性不作为当前页面图片 |
| 科耘漏图 | SVG 的 OSS 裁切参数采用等价 URL 编码，或资源地址为相对地址 | 解析 URL 与 query 后检查裁切参数，保留完整请求地址；换卷资源读取同步支持相对地址 |
| 19 个适配器误报换卷 | 答卷不变，仅评分框为空/被清空或出现“未评分”便返回成功；可让连续阅卷重复处理当前卷 | 保留实际图片或平台标识变化，评分状态单独变化继续等待 |
| C30 同卷接口重取 | API 时间戳改变但答卷资源不变 | 等待资源变化，接口刷新时间不单独触发下一份 |
| 慧阅卷等待不结束 | iframe 消失后提前返回，跳过每轮超时检查 | 超时检查在读取 iframe 前执行 |

19 个适配器为：C30、海云智评、华翰云旧部署、云阅卷好分数、阅小二、慧学星、慧阅卷、科耘、酷鱼、睿芽、五岳、威科姆、鑫考、鑫考内网、鑫考校园、54学霸、粤教翔云、云阅卷、新教育。新教育的考试与作业委托函数分别覆盖。

这些受控问题在 1.21.19.0、1.21.20.0、当前 stable 均存在，属于存量问题。受控回归采用真实适配器函数、合成 DOM 与虚拟时钟，检查同卷空分/清空/零分、新卷资源或标识变化、接口重取、相对地址、编码形式和 iframe 离开。它们证明代码分支的行为；各平台真实保存与换卷时序仍需现场样本。

本次兼容用例共 46 项，三个基线版本各有 26 项失败、20 项通过；修复后全部通过。全套回归、构建和产物分派检查结果在 PR 中登记，场景工具另有完整性与只读服务用例。

## 发布检查与后续范围

此前的发布验证缺少原稳定版已支持页面形态的对照，现有好分数用例只覆盖一种裁切路径，又未保留真实账号现场。路径解析规则变为图片过滤规则后，构建与受控测试仍会通过，无法发现被遗漏的原始图格式。

后续执行 [现场留档与回归](../testing/platform-scenes.md)：获授权账号先留档；所有变更路径及公共依赖列明受影响平台；旧格式与新格式、同卷与新卷、试改/普通/无人模式分别核验并标明证据等级。PR 模板要求报告本地档案、兼容对照及覆盖缺口。

本次新增场景工具只提供冻结 DOM 的适配器回放。原始前端程序和接口样本保留供后续交互模型使用；服务端实现与真实保存行为仍依赖平台及相应授权任务。跨平台改动进入面向 dev 的 PR 验证，与已发布的好分数稳定版修复分别管理。
